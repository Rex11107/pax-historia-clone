# Le corti dei motori

Ogni motore del gioco è giudicato da una corte indipendente: un accusatore studia il codice e scrive un atto d'accusa; una giuria di tre verifica ogni capo sul codice, aggiunge ciò che l'accusa non ha visto, vota e scrive un verdetto con le correzioni in ordine. Regole comuni: `brief.md`.

| 02 | Intelligenza delle nazioni non giocanti | fatto | **fatto** |
| 03 | Economia, finanze, commercio e risorse | fatto | **fatto** |

| 06 | Diplomazia, alleanze, stati soggetti | fatto | **fatto** (`06-diplomazia/verdetto.md`; accusa e giuria nella stessa sessione) |
